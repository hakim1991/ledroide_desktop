# Kanban

Gestionnaire de tâches façon Kanban.

- Plusieurs tableaux ; colonnes par défaut « À faire / En cours / Terminé » (ajout, renommage, suppression, réorganisation).
- Cartes : titre, description, priorité (couleur), échéance (mise en évidence si dépassée), étiquettes.
- Glisser-déposer des cartes entre et dans les colonnes, ordre persistant.
- Recherche et filtre par priorité / étiquette.
- Données stockées dans SQLite (`backend/todo-kanban.db`).
