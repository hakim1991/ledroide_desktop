Génération
Le prénom, le nom, le nom complet et l'email d'une même ligne correspondent à la même personne ; la ville, le code postal et l'adresse complète sont cohérents entre eux.
Les IBAN (clé RIB + clé IBAN) et les SIRET/SIREN (Luhn) générés sont valides mais fictifs.
Regex : littéraux, ., \d \w \s, [a-z0-9], [^…], groupes ( | ), ? * + {n} {n,m}.
