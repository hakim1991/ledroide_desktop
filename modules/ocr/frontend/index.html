🧩 Tesseract n'est pas installé

Ce module utilise Tesseract OCR, un logiciel libre à installer séparément (environ 80 Mo). Une fois installé, revenez ici et cliquez sur Revérifier.

  1. Téléchargez l'installateur Windows maintenu par l'université de Mannheim (UB-Mannheim) : github.com/UB-Mannheim/tesseract/wiki — fichier tesseract-ocr-w64-setup-….exe.
  2. Pendant l'installation, dépliez Additional language data et cochez French (pack fra), ainsi que les autres langues utiles.
  3. Gardez le dossier proposé (C:\Program Files\Tesseract-OCR) : il est détecté automatiquement. Sinon, indiquez le chemin de tesseract.exe ci-dessous.
