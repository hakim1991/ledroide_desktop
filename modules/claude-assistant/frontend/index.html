🔑 Clé d'API Anthropic requise

Ce module appelle l'API Claude d'Anthropic : il a besoin de votre clé d'API personnelle.
  1. Créez une clé sur console.anthropic.com (rubrique « API Keys »).
  2. Dans LedroideDesktop, ouvrez le menu « Variables ».
  3. Ajoutez la variable ANTHROPIC_API_KEY avec votre clé comme valeur.
  4. Revenez ici et cliquez sur « Vérifier à nouveau ».
La clé est lue à chaque requête par le backend local ; elle n'est jamais affichée ni transmise à cette interface.
⚠ La bibliothèque Python « anthropic » n'est pas installée : désactivez puis réactivez le module, ou installez-la depuis le menu « Bibliothèques ».
