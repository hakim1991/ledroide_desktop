# Snippets

Bibliothèque personnelle de bouts de code et de commandes.

- Snippet = titre, langage, tags, description, contenu ; favoris
- Recherche plein texte (tous les mots), filtres par langage, tag et favoris ; tri récents / plus utilisés / titre
- Copie en un clic (bouton ⧉, double-clic, `Entrée`, `Ctrl+Maj+C`) avec compteur d'utilisation
- **Placeholders** `{{nom}}` ou `{{nom:valeur par défaut}}` : un formulaire avec aperçu les demande avant la copie (« Copier brut » pour les ignorer)
- Coloration syntaxique intégrée (sans dépendance) : Python, JavaScript, TypeScript, SQL, Bash, PowerShell, JSON, HTML, CSS, YAML, Go
- Import / export JSON (`{"items": [...]}` ou tableau ; les doublons titre + contenu sont ignorés à l'import)

Stockage dans la base SQLite du module. Raccourcis : `Ctrl+N` nouveau, `Ctrl+F` recherche, `↑/↓` navigation, `E` modifier, `Suppr` supprimer, `Ctrl+S` enregistrer, `Échap` annuler.
