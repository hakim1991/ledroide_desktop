🔑 Connexion au proxy LiteLLM

Ce module dialogue avec votre proxy LiteLLM (API compatible OpenAI). Il a besoin de son URL et d'une clé.
  1. Dans LedroideDesktop, ouvrez le menu « Variables ».
  2. Ajoutez LITELLM_BASE_URL : l'URL du proxy (ex. https://litellm.mondomaine.fr).
  3. Ajoutez LITELLM_API_KEY : votre clé (sk-…).
  4. Revenez ici et cliquez sur « Vérifier à nouveau ».
La clé est lue par le backend local et n'est jamais transmise à cette interface.
⚠ La bibliothèque Python « openai » n'est pas installée : désactivez puis réactivez le module, ou installez-la depuis le menu « Bibliothèques ».
