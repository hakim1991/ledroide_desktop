# 🎨 Couleurs

- **Sélecteur** avec conversions éditables : HEX, RGB, HSL, HSV, CMYK (clic pour copier le code CSS).
- **Pipette écran** : utilise l'API `EyeDropper` du navigateur ; à défaut, une capture d'écran
  (Pillow `ImageGrab`) s'affiche et vous cliquez sur le pixel voulu, avec loupe de zoom.
- **Harmonies** : complémentaire, analogues, triadique, complémentaires adjacentes, tétradique, nuances et teintes.
- **Contraste WCAG** : ratio, niveaux AA / AAA (texte normal et grand texte).
- **Palette enregistrée** (SQLite) : ajout, renommage, suppression, export CSS / JSON / GIMP (.gpl).
