🌍 Traduire un fichier

Le fichier est traduit par lots avec l'API Claude, en conservant sa structure : seuls les textes sont traduits, le reste (minutages, code, liens, clés, variables, mise en forme) est préservé à l'identique.

Déposez un fichier ici ou cliquez pour le choisir
SRT, VTT, Markdown, TXT, DOCX, JSON — jusqu'à 10 Mo

🧩 JSON i18nSeules les valeurs sont traduites ; clés et variables {x}, {{x}}, %s, ICU… intactes.
