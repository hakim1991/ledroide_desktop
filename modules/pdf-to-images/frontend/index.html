⚙️ Prérequis : installer Poppler (Windows)
  1. Téléchargez Release-xx.xx.x-0.zip (section « Assets ») sur poppler-windows/releases.
    ⚠️ Pas « Source code » : il ne contient aucun .exe.
  2. Extrayez-le, par exemple dans C:\poppler-26.09.0. Le fichier Library\bin\pdftoppm.exe doit exister.
  3. Ajoutez le dossier C:\poppler-26.09.0\Library\bin au PATH :
    Menu Démarrer → « Modifier les variables d'environnement pour votre compte » → Path → Modifier → Nouveau.
  4. Vérifiez dans un nouveau terminal : 
    pdftoppm -v
  5. Fermez complètement LedroideDesktop puis relancez-le.
