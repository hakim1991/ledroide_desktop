# Moniteur système

Tableau de bord temps réel basé sur `psutil` (à installer via le bouton « dépendances »).

- Cartes : CPU (total et par cœur), mémoire, swap, disques (par partition), débit réseau montant/descendant, batterie, durée de fonctionnement, informations OS.
- Graphiques en direct (60 dernières secondes, rafraîchissement chaque seconde).
- Table des processus : tri par CPU / mémoire / nom / PID, recherche, « Terminer le processus » avec confirmation.

Certains processus système nécessitent des droits administrateur pour être terminés.
