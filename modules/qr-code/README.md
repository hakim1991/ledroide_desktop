# 🔳 QR Code

**Générer** : texte, URL, réseau WiFi (SSID, mot de passe, WPA/WEP/aucune) ou carte de contact (vCard 3.0).
Réglages : taille, niveau de correction d'erreurs (L/M/Q/H), couleurs, marge, fond transparent.
Aperçu en direct et téléchargement en **PNG** ou **SVG** (vectoriel).

**Lire** : glissez, sélectionnez ou collez (Ctrl+V) une image ; le module détecte et décode un ou plusieurs
QR codes (OpenCV), surligne leur position et analyse les codes WiFi.

Dépendances : `qrcode[pil]`, `opencv-python-headless` (bouton « Installer les dépendances »).
